# Spec Delta｜空間設定

## Purpose

提供配置檢查所需的空間三軸尺寸，讓使用者以公分設定現有空間，並確保只有符合已確認正整數限制的尺寸能成為檢查依據，避免無效輸入產生錯誤的符合判定。

## ADDED Requirements

### Requirement: 設定三軸空間尺寸

系統 SHALL 提供空間長、寬、高三軸設定並標明公分與平面方向，使使用者能辨別商品寬／深對應的空間方向；已接受的尺寸 SHALL 用於配置檢查。（F01）

#### Scenario: 接受正整數空間
- **WHEN** 使用者設定長 100、寬 80、高 40 公分的空間
- **THEN** 系統接受三軸設定並依該空間呈現配置區與檢查依據
- **AND** 介面標明長／寬與商品寬／深的對應方向

### Requirement: 空間尺寸限定正整數公分

系統 MUST 僅接受三軸均為正整數的空間尺寸，不得默默將小數截斷、四捨五入或將負數轉為正數；未建立有效空間時 MUST NOT 顯示配置符合全部限制。（F01、使用者已確認限制；不等於 AC07 全部核准）

#### Scenario: 拒絕非正整數數值
- **WHEN** 使用者嘗試設定任一軸為空白、0、負數、非整數小數或非數字
- **THEN** 該輸入不被接受為有效空間尺寸
- **AND** 不得以該無效值產生符合全部限制的判定

#### Scenario: 尚無有效空間
- **WHEN** 使用者尚未建立三軸均有效的空間
- **THEN** 系統不顯示「符合全部限制」
