# Spec Delta｜商品目錄

## Purpose

提供單一品牌的有限真實收納商品，讓使用者自行瀏覽並核對尺寸與規格來源。目錄保留資料既有的尺寸方向、小數及備註，使配置檢查可追溯至所使用的靜態資料，而不宣稱代表完整商品線。

## ADDED Requirements

### Requirement: 樹德靜態商品目錄

系統 SHALL 使用 `product-info/shuter-products.json` 的 23 筆樹德商品作為本次唯一商品目錄，呈現品牌、名稱／型號、寬／深／高、公分與規格來源，供使用者自行選擇；SHALL NOT 自動篩選、推薦、跨品牌整合或即時更新商品。（F02）

#### Scenario: 瀏覽並核對商品
- **WHEN** 使用者開啟商品目錄
- **THEN** 能瀏覽 23 筆樹德商品，包含 `DB-26 大房子整理盒`
- **AND** 該商品顯示寬 51.7、深 37.05、高 18.55 公分，來源指向 JSON 的 `sourceUrl`
- **AND** 空間尺寸的選擇不會自動刪除或隱藏不合尺寸商品

### Requirement: 保留尺寸方向與原始精度

系統 MUST 以商品資料的 width／depth／height 分別代表寬／深／高，顯示與檢查均保留原始小數，不得為配合空間整數輸入而取整或互換寬深。（F02、F04）

#### Scenario: 小數商品維持原始尺寸
- **WHEN** 使用者選擇寬 51.7、深 37.05、高 18.55 公分的 DB-26
- **THEN** 目錄、配置與檢查使用相同尺寸，深度不被改成 37 或 38，高度不被改成 18 或 19

### Requirement: 保留尺寸來源限制

系統 SHALL 在可核對的商品資訊中呈現資料的尺寸備註，保留外徑、未明示內外尺寸、摺疊商品使用展開尺寸等差異；MUST NOT 把來源不明的內外尺寸宣稱為已確認外部最大尺寸，或把工具檢查解讀為實物保證。（F02）

#### Scenario: 核對不同商品備註
- **WHEN** 使用者查看 DB-2621、DB-26 與 FB-5336DR 的商品資訊
- **THEN** 分別可讀到「官網標示為外徑」、「官網未標明是外尺寸或內尺寸」、「官網標示為外徑；摺疊式，這裡用展開後的尺寸」
- **AND** 符合判定明確以所列尺寸為依據
