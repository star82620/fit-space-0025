# Fit Space｜互動式居家收納配置規劃工具

以真實商品尺寸，在購買前嘗試不同數量與排列。純前端應用程式，使用樹德 23 筆靜態商品資料，提供 2D 配置及自動尺寸檢查。

> 本專案為課程作業練習，商品資料與圖片版權屬樹德。

## 安裝與啟動

需要 Node.js 22.12 以上與 npm。套件管理已依使用者決定由 pnpm 改為 npm，使用 `package-lock.json`。

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址。正式產物使用 `npm run build` 建置，`npm run preview` 預覽；這兩個指令不會部署網站。

## 操作方式

1. 輸入空間寬（左右）、深（前後）、高，按「套用空間」。
2. 在目錄選擇商品，按「放入配置」，商品先放在原點。
3. 拖曳商品調整位置；每件都有獨立編號、「旋轉」與「移除」按鈕。按一次旋轉 90 度，再按一次回到原方向，左上角位置不變。
4. 查看「配置檢查結果」及「異常明細」，依提示繼續調整。

空間限定 **1～999 的整數公分**，前後空白會忽略，輸入須由數字組成；小數、負數、科學記號均不接受。輸入中不提示錯誤，離開欄位或套用時才顯示。無效修改會繼續使用上一次有效空間，並明確標示。

商品放入時依原始寬、深擺放；使用者可逐件手動旋轉 90 度，交換寬深，高度不變。系統不自動旋轉或建議方向。越界、重疊或高度超限只提示，不阻止旋轉或自動修正位置；任何違規存在時，整體均不符合全部限制。邊緣貼齊、共邊、共角及高度等於空間上限都合法。

有效空間、商品位置與各件旋轉狀態保存在瀏覽器 `localStorage`（`fit-space:layout:v1`），重新整理後恢復；舊資料缺少方向欄位時視為原方向。損毀、不相容或未知商品資料會被忽略；儲存失敗會提示並從空白狀態開始。資料只在自己的瀏覽器，不跨裝置同步，沒有帳號。

## 商品資料與精度

唯一目錄為 [`product-info/shuter-products.json`](product-info/shuter-products.json)，既有數值已是公分，不再從毫米換算。保留原始小數，包含 37.05 cm、18.55 cm。幾何檢查採十進位精確轉換的整數定點，目前最小刻度 0.01 cm；畫面像素與真實尺寸分離，不以寬鬆誤差值放行越界。

商品來源、外徑／內外尺寸未明、摺疊品採展開尺寸等備註會一併呈現。判定僅依所列尺寸，不保證實物適配。圖片直接引用 JSON 官網網址，失敗時提供替代圖示，名稱、尺寸及放入功能繼續可用。

## 品質檢查與測試

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run test:geometry
npm run test:e2e
```

瀏覽器自動化測試使用本機已安裝的 Google Chrome（Chromium 引擎），不另下載瀏覽器。geometry project 不需要啟動瀏覽器或伺服器；e2e project 自動啟動 127.0.0.1:5173，如該位置已有本專案伺服器則沿用。兩組都使用 Playwright Test runner。

`tests/geometry/quality-cases.ts` 定義 40 筆固定品質案例（20 符合、20 不符合），預期答案獨立自規格轉錄；`rotation-cases.ts` 另有 14 筆旋轉固定案例，原 40 筆未修改。另測輸入、資料完整性、精度、安全範圍、實例狀態與保存。重大尺寸誤判為「系統判符合但標準答案違規」，目標為 0。誤判率＝重大尺寸誤判數 ÷ 系統判符合數；若分母為 0，記為無法計算，不能宣稱 0%。

瀏覽器測試清單與實際 Playwright MCP 證據分別保存在 [`e2e-testing.md`](openspec/changes/archive/2026-11-09-build-mvp-core/e2e-testing.md) 與該 change 的 `e2e-evidence/`。自動化測試的通過不自動勾選 MCP 清單；只有實際操作留證後才更新。

## 目前限制

僅支援矩形俯視配置及逐件手動切換原方向／90 度；不提供任意角度旋轉、堆疊、全部清空、跨品牌、自訂商品、推薦、最佳配置、3D、輸出、即時價格庫存或購買功能。沒有後端、商品 API 或資料庫；行動裝置尚未列為本次正式驗收條件。
