# Fit Space｜互動式居家收納配置規劃工具

讓已有固定收納空間、準備添購收納用品的居家使用者，透過真實商品尺寸、2D 互動配置與即時尺寸檢查，在購買前判斷收納品是否放得下。

## 專案狀態

MVP 開發中，以規格驅動開發（SDD）搭配 OpenSpec 進行。

## 執行方式

（待補：完成 change 1 實作後補上安裝與啟動指令）

## 測試方式

（待補：端對端測試以 Playwright 執行，測試清單位於各 change 的 `e2e-testing.md`）

## 專案結構

| 路徑 | 內容 |
|---|---|
| `sdd-input.md` | SDD 輸入資訊摘要，產品需求的來源 |
| `openspec/config.yaml` | 技術棧與專案原則 |
| `openspec/changes/` | 進行中的變更；完成後移至 `archive/` |
| `openspec/specs/` | 歸檔後合併而成的正式規格 |
| `AI-LOG.md` | AI 協作紀錄與反思 |

## 開發流程

每個變更依序執行：探索 → 提案 → 審查 → 實作與端對端測試 → 驗證 → 歸檔。
